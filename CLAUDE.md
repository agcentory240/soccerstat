# CLAUDE.md

Основные инструкции проекта находятся в [`AGENTS.md`](AGENTS.md). Прочитай их перед любыми изменениями, а также профильные документы в [`docs/ai/`](docs/ai/).

Кратко:

- Все рассуждения, планы, ответы, комментарии и документация — **на русском языке**.
- Код и идентификаторы — на английском по общепринятым конвенциям.
- Это единый npm-workspaces монорепозиторий: команды запускаются из корня.
- Перед завершением задачи выполни `npm run lint` и `npm run build`.
- Не коммить `.env`, секреты, `node_modules/`, `dist/`, `app/debug/`.
