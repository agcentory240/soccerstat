# @soccerstat/api

Backend SoccerStat: NestJS 12, TypeORM, PostgreSQL, RabbitMQ, Playwright.

Пакет входит в npm-workspaces монорепозиторий. Установка зависимостей и запуск — **из корня репозитория**:

```bash
npm install
DB_HOST=localhost npm run dev:api
```
