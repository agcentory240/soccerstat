# @soccerstat/frontend

Frontend SoccerStat: React 19, Vite 8, TypeScript, Zustand, React Router, Tailwind CSS 4.

Пакет входит в npm-workspaces монорепозиторий. Установка зависимостей и запуск — **из корня репозитория**:

```bash
npm install
npm run dev:web
```
